# Orbit — Space Exploration Quiz

A colorful, browser-based space quiz built as a single HTML file. No server, package installation, or external dependencies required.

## Play

Open `index.html` in any modern web browser, choose a difficulty, and start exploring.

## Features

- Ten questions at each of three difficulty levels: Easy, Medium, and Hard
- Per-question countdown timer: 20, 15, or 10 seconds, depending on difficulty
- Progress bar and live score counter
- Animated green feedback for correct answers and red shake feedback for incorrect answers
- Results screen with a score-based emoji reaction and replay button
- Responsive layout, light and dark color schemes, and reduced-motion support

## Publish with GitHub Pages

1. Add `index.html` and `README.md` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your default branch and the **`/ (root)`** folder, then save.

GitHub Pages will provide a URL for your published quiz after deployment finishes.
